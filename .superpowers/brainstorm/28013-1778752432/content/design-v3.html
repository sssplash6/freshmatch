Motion spec new

Product register: motion conveys state, not personality. All durations 150–280ms. Ease-out-expo throughout. No bounce, no elastic, no choreography on load.

Question slide (forward) 280ms translateX(32px→0) + opacity — ease-out-expo
Question slide (back) 280ms translateX(-32px→0) + opacity — ease-out-expo
Option selection (color + bg) 180ms color, background-color — ease-out-quint
Option dimming 180ms color — ease-out-quint
Continue button (enable) 200ms opacity (0.2→1) — ease-out-quint
Progress bar fill 500ms width — ease-out-expo
Phase enter (Interstitial, Results) 320ms opacity + translateY(12px→0) — ease-out-expo
prefers-reduced-motion all durations → 0.01ms, transforms skipped
